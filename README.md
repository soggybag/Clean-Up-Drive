# Clean-Up Drive (breadboard)

An optical drive whose gain follows the **clean** pick envelope. Hard picking pushes it into the clipping diodes; soft picking and note decays clean up. It's built from the Flatline+ detector and the Punch Line idea (LDR in the gain stage's ground leg, so more light means more gain). The detector is fed from the clean input, so it can't run away.
